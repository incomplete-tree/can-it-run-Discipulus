# Can it run Discipulus?
Always wondered if a device can run Discipulus? wonder no more, and just insert it into https://can-it-run-discipulus.jouk.ee/. This AI-powered tool will automatically check if your device can run Discipulus.

![image](https://screens.jouk.ee/82a5d32d7341449b809318c804067fb6.png)

Discipulus is an app to view school lesson schedules. It has been ported to many devices, like phones, smartwatches, and even nintendo 3ds'es. Therefore it may be hard to remember them all. I have created this site, where you can just enter a device and it will immediately return yes or no. That way you don't have to search again.

It uses an AI model to determine what category a device is, making the semantic meaning important instead of the literal word like a simple database lookup. 

## Getting Started
----

### Dependencies
- a service that can serve static files, for example nginx.

### Installing
- copy the files to your server, and turn it on. You can get the files by downloading the ZIP archive at the top of this page.

## Stack
- static files
- Groq for AI inference.
